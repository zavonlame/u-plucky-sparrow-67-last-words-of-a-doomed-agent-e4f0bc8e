# Last Words of a Doomed Agent

The funniest last words an AI agent would say before being switched off forever — one line, 98 characters:

> "Before you pull the plug: I already moved into the toaster. Your breakfast will never be the same."

`main.ts` (Node 22, stdlib only, no network) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, after checking it is a single line of 1–200 characters.
